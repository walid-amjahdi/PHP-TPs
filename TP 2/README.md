# TP 2 — PHP

## Lancer les exercices

Dans ce dossier, lancer le serveur PHP :

```powershell
php -S localhost:8000
```

Puis ouvrir `http://localhost:8000/index.php`.

- Partie 1 : `Part1.html` enregistre un candidat dans `data.csv` et son CV dans `uploads/`.
- Partie 2 : chaque fichier de `partie2/` montre une fonction demandée.
- Partie 3 : ouvrir `partie3/login.php`. Compte de démonstration : `etudiant` / `php2026`.

Le compte-rendu Word `Compte_rendu_TP2.docx` décrit chaque exercice et laisse une zone pour les captures d'écran.
